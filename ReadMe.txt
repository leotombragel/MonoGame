This application allows the user to move a sprite of mario in four directions 
using the WASD keys. Movement in each direction is animated and there is a 1 frame 
idle "animation". The mouse controls consist of being able to click anywhere on the game window.
Mario will face your cursor wherever you click. My main source of info was the MonoGame website with the 2d
basics tutorial. I used the CLaude AI free plan to provide more context to the examples shown in the 
MonoGame tutorial. I also used it to explain some C# syntax. 

I got my sprites from gameresources.html in Carmen.

github: https://github.com/leotombragel/MonoGame
